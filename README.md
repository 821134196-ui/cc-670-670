# 工厂危险作业监护人替换与现场复核系统

危险作业进行中需要更换监护人时，**必须先停工**，原监护人与接班人把风险、隔离措施
交接清楚并分别签认，经系统复核与班组长审批后才能复工。系统在复工时强制执行现场
安全红线，全程留痕，可追溯暂停 → 离场 → 接班 → 复工的完整顺序。

技术栈：Python 3.11 · FastAPI · SQLAlchemy 2 · SQLite · Vue 3 + Vite。
门禁与通知均为**本地模拟**，无任何外部服务依赖。

## 业务流程

```
作业中 ──停工发起交接──▶ 停工 PAUSED
   原监护人在现场逐条核对风险/隔离并签认（OUTGOING_SIGNED）
   原监护人离场（门禁回执）            ┐
   接班人到场（门禁回执）              ├─ 系统实时计算“无人监护时段”
   接班人逐条核对并签认（FULLY_SIGNED）┘
   闭环全部未完成事项 ──申请复工──▶ 系统硬校验
      ├─ 不通过：直接拦截，记录驳回原因，不进入审批
      └─ 通过 ──▶ 班组长复核 ──批准瞬间再次硬校验──▶ 复工 RESUMED（锁定空档快照）
```

交接页自动带出：正在进行的作业与许可、逐条风险/隔离措施及未完成事项、
双方签认状态与在场状态、近期门禁回执、无人监护时段与交接历史时间线。

## 强制的安全规则（测试覆盖）

1. **两人两账号，禁止共用/代签**：签认接口比对登录令牌与交接单上的当事人，
   不是本人一律 403；接班人不得与原监护人为同一人。
2. **禁止重复签认**：任一方重复提交返回 409；客户端携带幂等 nonce 的重放
   只返回首次结果，时间线不增加事件。
3. **禁止重复交接**：同一许可同时只允许一个未闭环交接单
   （应用层 + SQLite 部分唯一索引 `uq_open_handover_per_permit` 双重保证）。
4. **接班人资质红线**：资质类型缺失或已过期，系统直接拦截复工，申请进不了审批。
5. **许可红线**：许可过期/关闭，不能复工；申请通过后、批准前到期同样拦截。
6. **现场无人监护红线**：复工当下必须有接班人**有效入场回执**；
   签认也要求本人在现场。签认后又离场再申请复工同样被拦。
7. **门禁延迟回执不回填**：在场判断只使用“判定时刻之前**已到达**”的回执。
   人已过闸但回执因网络延迟未到时，系统视其为不在场，不补造在场时间；
   复工批准时把无人监护时长**快照锁定**，事后到达的任何回执都不能改写历史。
8. **未完成事项**：风险/隔离核对项中存在 OPEN 事项时不能复工，页面可闭环。
9. **顺序强制**：必须原监护人先签、接班人后签；签认须本人在现场。

## 关键接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/login` | 登录换取个人令牌 |
| GET | `/api/permits/{id}/handover-page` | 交接页聚合数据 |
| POST | `/api/permits/{id}/pause` | 停工并发起交接（指定接班人） |
| POST | `/api/handovers/{id}/sign` | 本人签认（role + item_checks + nonce） |
| POST | `/api/access-events` | 模拟门禁回执（event_time + delay_seconds） |
| POST | `/api/checklist-items/{id}/confirm` | 闭环未完成事项 |
| POST | `/api/handovers/{id}/request-resume` | 申请复工（系统硬校验） |
| POST | `/api/resume-requests/{id}/decision` | 班组长批准/驳回（批准时再校验） |
| GET | `/api/leader/overview` | 空档监控 + 待审批 + 作业一览 |
| GET | `/api/handovers/{id}/timeline` | 交接历史时间线 |
| POST | `/api/dev/clock` | 演示用：快进系统时间（验证到期场景） |

## 手动验证场景

- **换班空档**：停工 → 原监护人签认 → 门禁“原监护人离场” → 等待 →
  “接班人入场” → 签认 → 复工；班组长复核台实时显示空档秒数，复工后锁定。
- **资质过期**：交接时接班人选“赵德柱”，可完成交接但复工被系统拦截。
- **许可过期**：打开 P-2026-002，用页面底部“时钟快进 35 分钟”后走完交接，
  复工被拦截。
- **门禁延迟**：把过闸时间设为 5 分钟前、回执延迟填 300；在回执发送前
  接班人无法签认；发送后历史时刻仍判定为不在场。
- **重复签认/代签**：用同一账号重复点签认，或用原监护人账号替接班人签，均被拒。
